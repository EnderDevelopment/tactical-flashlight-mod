# Tactical Flashlight Mod

A military-style flashlight mod for Minecraft Fabric.

## Features

- Custom military-style flashlight item
- Keybind to toggle flashlight on and off

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/tactical-flashlight-mod/releases)
2. Place the JAR file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

- Obtain the flashlight item in-game
- Press the `F` key to toggle the flashlight on and off

## Configuration

The mod does not have any configuration files. All settings are hardcoded in the mod.
